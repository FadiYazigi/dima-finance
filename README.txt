DIMA FINANCE 1.4 - ANDROID PWA

This package is a Progressive Web App, NOT an APK.

1. Extract all files.
2. Publish the files together on an HTTPS website (for example GitHub Pages).
3. Open the HTTPS address in Chrome on Android.
4. Chrome menu > Add to Home screen > Install (wording may vary).
5. Launch Dima Finance from the phone home screen.

IMPORTANT: Each browser/device has separate records. Data from Windows 1.3 is NOT automatically migrated or synchronized. CSV export is backup only, not import. Back up regularly. Avoid entering real financial records until you have tested persistence and backup.

Opening index.html directly from phone storage may not permit PWA installation or reliable storage. Hosting over HTTPS is required for service workers.
